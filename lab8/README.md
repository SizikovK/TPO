# Лабораторная работа № 8. Профилирование ПО

## Цель и условия

Оценить потребление ресурсов QEMU с OpenBMC. Стенд: CachyOS, QEMU ARM 11.1.1, `romulus-bmc`, OpenBMC `2.9.0-rc1`, гостевая RAM 256 МиБ.

Проведены два замера по 15 секунд: простой и последовательные запросы Redfish. Все 93 запроса завершились с HTTP 200. Сбор выполнен скриптом [measure.sh](measure.sh).

## Сбор метрик

```bash
sudo perf stat -e cycles,instructions,cache-misses -p 534280 -- sleep 15
vmstat 1 16
nmon -F network.nmon -s 1 -c 15
ps -p 534280 -o rss=
```

`perf` подключён к работающему QEMU. RSS измерялся раз в секунду. CPU хоста рассчитан как `100 - id` по vmstat без первой строки; RSS переведён из КиБ в МиБ.

## Результаты

| Метрика | До теста (простой) | Во время теста |
| --- | ---: | ---: |
| Средняя занятость CPU хоста, % | 19,13 | 31,20 |
| Средняя резидентная память QEMU, МиБ | 215,80 | 216,65 |
| `cycles` процесса QEMU | 12 382 703 311 | 61 531 171 927 |
| `instructions` процесса QEMU | 12 538 308 100 | 92 853 172 544 |
| `cache-misses` процесса QEMU | 281 507 859 | 879 455 767 |
| `nmon`: средний приём/передача `lo`, KB/s | 28,54 / 28,54 | 30,13 / 30,13 |
| `nmon`: средний приём/передача `wlan0`, KB/s | 28,18 / 3,20 | 0,47 / 1,19 |

CPU хоста и сеть включают фоновые процессы; сетевые показатели nmon нельзя целиком приписывать QEMU. Запросы выполнялись через `lo`. [Исходные измерения](results-U095PQ/) сохранены отдельно.

## Предложения по оптимизации

- Сохранить `-nographic`: графический интерфейс для этого стенда не нужен.
- Сохранить `-m 256`: по этому тесту оснований увеличивать гостевую RAM нет.
- Сравнить `-accel tcg,tb-size=64` и `-accel tcg,tb-size=128`: меньший кеш транслированного кода может экономить память ценой повторной трансляции. Это предложение, его эффект не измерялся. [Документация параметров QEMU](https://www.qemu.org/docs/master/system/invocation.html).

## Вывод

При нагрузке CPU хоста вырос с 19,13% до 31,20% (**+12,07 п.п.**), а память QEMU — с 215,80 до 216,65 МиБ (**+0,85 МиБ**). Основное изменение — рост вычислительной нагрузки; потребление памяти почти не изменилось.
