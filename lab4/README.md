## 5. Тесты с неверными данными

Функция `test_invalid_credentials()` проверяет два набора данных:

| Проверка | Логин | Пароль |
| --- | --- | --- |
| Неверный логин | lab4_missing | 0penBmc |
| Неверный пароль | root | WrongLabPassword1! |

Шаги:

1. Ввести выбранные данные.
2. Нажать Log in.
3. Проверить отказ во входе, наличие формы входа и отсутствие доступа к авторизованной странице.

Ожидаемый результат: неверные учётные данные отклоняются, доступ к авторизованной странице не предоставляется.

Вывод прогона:

```text
lab4/test_webui.py::test_invalid_credentials[wrong_username] PASSED      [ 33%]
lab4/test_webui.py::test_invalid_credentials[wrong_password] PASSED      [ 50%]
```

Неверные данные отклонены сервером с HTTP 401, форма входа остаётся доступной, авторизованная страница не открывается. Оба теста пройдены.

## 6. Тест блокировки учётной записи

Функция `test_account_lockout()`:

1. Прочитать настроенный порог неудачных попыток.
2. Если временная блокировка включена, выполнить указанное число неверных входов.
3. Проверить отказ с правильным паролем во время блокировки.
4. После истечения срока проверить восстановление входа.

Перед прогоном прочитана политика AccountService:

```bash
curl --noproxy '*' -k -sS -u root:0penBmc https://127.0.0.1:3443/redfish/v1/AccountService
```

Фрагмент ответа:

```json
"AccountLockoutDuration": 0,
"AccountLockoutThreshold": 0
```

В исходной конфигурации блокировка отключена. Результат автотеста:

```text
lab4/test_webui.py::test_account_lockout SKIPPED (Blocked: AccountLo...) [100%]
SKIPPED [1] lab4/test_webui.py:202: Blocked: AccountLockoutThreshold=0, блокировка отключена в образе
```

Тест блокировки реализован. Его выполнение заблокировано отсутствием включённой политики блокировки в текущем образе.

## 7. Два теста из лабораторной №3

### 7.1. Напряжение материнской платы

Функция `test_voltage_monitoring()`:

1. Выполнить вход.
2. Открыть Hardware status → Sensors.
3. Найти датчик напряжения материнской платы.
4. Проверить числовое значение в вольтах и допустимые пределы.

Вывод:

```text

SKIPPED [1] lab4/test_webui.py:147: Blocked: датчик матплаты и допустимые пределы не заданы; строки UI: ['No items available']
```

В таблице отсутствуют датчики. Проверка заблокирована, числовое измерение не выполнено.

### 7.2. Запись логов при ошибке

Функция `test_logs_on_error()`:

1. Войти и сохранить текущие записи Event logs.
2. Выполнить вход с неверными данными.
3. Войти с правильными данными.
4. Открыть Logs → Event logs.
5. Проверить новую запись Warning/Critical об ошибке авторизации в течение 60 с.

Вывод:

```text
lab4/test_webui.py::test_logs_on_error FAILED                            [ 83%]
```

Причина результата:

```text
E   Failed: После подтверждённой ошибки входа за 60 с нет новой записи Warning/Critical об авторизации в Event logs. Новые строки: set()
```

Неверный вход подтверждён. После повторного входа просмотрен Event logs: новая запись об ошибке авторизации за 60 с не появилась. Тест выявил отсутствие ожидаемой записи в журнале.
